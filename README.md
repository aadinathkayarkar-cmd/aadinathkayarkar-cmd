## 🚀 Featured Projects

### 🤖 G1Saathi – Agentic AI Healthcare Information Assistant
*Team project · Python, Flask, LangChain, Ollama, ChromaDB*

An agentic AI assistant that gives accessible, source-grounded health information instead of unverified chatbot answers.

- A Workflow Planner routes each query across 13 specialised agents for retrieval, analysis, and verification
- RAG over trusted medical sources (WHO, CDC) using ChromaDB and nomic-embed-text embeddings, with local LLM inference through Ollama
- Two-layer safety: a Safety Gate for emergency or high-risk queries, and a Grounding Verifier that removes unsupported claims
- Provides health information only, not diagnosis or prescriptions

### 📱 HelpMeOut – College Service Provider App
*Team project · Java, XML, Firebase Firestore, Android Studio*

An Android app that helps students living away from home find local service providers such as food, accommodation, and repairs.

- Categorized service listings and an admin module for managing service information
- WhatsApp integration to contact providers directly, and Google Maps API for location
- Firebase Firestore as the cloud database

### ✈️ AeroTwin – AI-Driven Digital Twin for UAV Propulsion Monitoring
*Python, Scikit-learn, Random Forest*

A physics-informed digital twin for predictive-maintenance analysis of UAV propulsion.

- Built an end-to-end ML pipeline on approximately 42,000 synthetic telemetry records (33,600 train / 8,400 test)
- Random Forest classifier reached approximately 85.7% test accuracy on operating and degradation states
